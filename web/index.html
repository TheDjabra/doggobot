Wheels up. Drives forward while green is detected and reverses while red is, so thresholds can be checked against real motion without speaking a command. Requires ARM. Times out after five minutes.

Matching pixels are tinted on the video above. Widen until the target is solidly covered, then narrow until nothing else is. Hue is which colour, saturation is how vivid, value is how bright: in poor light it is usually the saturation and value floors that need lowering, not the hue. Red occupies two hue bands because hue wraps around, so it has two sets. Save writes the thresholds to the car so they survive a restart.
